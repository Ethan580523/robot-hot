🤖 关于 ROBOT HOT

ROBOT HOT 是一个机器人产业动态聚合平台，自动抓取多个机器人行业信息源，按品类分类整理，生成每日动态报告。

📊 数据来源

  • IEEE Spectrum Robotics
    spectrum.ieee.org/feeds/topic/robotics.rss
    RSS
  • robot.tv
    news.robot.tv/feed.xml
    RSS
  • The Robot Report
    therobotreport.com/feed/
    RSS

🏷️ 分类体系

🚀 产品发布 — 新产品发布、版本更新、量产消息

📊 行业动态 — 企业融资、政策法规、市场分析、工厂部署

📄 论文研究 — 学术论文、开源项目、数据集、benchmark

💡 观点技巧 — 行业评论、趋势分析、技术观点

⚙️ 技术栈

纯 Node.js 实现，零第三方依赖：

Node.js 原生 HTTP RSS 解析 Vanilla JS CSS Grid

🔄 更新机制

• 首次启动自动抓取数据

• 首页点击「刷新」按钮可手动触发抓取

• 可配置 cron 定时任务每小时自动抓取

• 数据存储在 data/ 目录下为 JSON 文件

📡 API 端点

GET /api/feed — 全部动态（支持分类筛选和分页）

GET /api/daily — 日报日期列表

GET /api/daily/YYYY-MM-DD — 指定日期日报

GET /api/stats — 统计信息

GET /api/refresh — 手动触发抓取
